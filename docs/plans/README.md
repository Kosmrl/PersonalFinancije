# Feature plans

`architect` writes one plan per feature here, named `YYYY-MM-DD-<short-slug>.md`.

Each plan starts with a status line:

- **Draft**: written, waiting for the user's approval
- **Approved**: the user signed off, implementation can start
- **Done**: implemented, tested and reviewed

Plans are the record of *why* things were built the way they were. Keep them after a feature ships.
